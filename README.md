# SkinLesionSystem
医学图像处理

# 基于深度学习与大语言模型的皮肤病变图像分割系统


一个基于 Python、PyTorch 和 U-Net 的皮肤病变图像分割项目，使用 PH² 皮肤镜图像数据集进行模型训练与评估，实现皮肤病变区域的自动分割，并计划结合 Streamlit 与大语言模型构建可交互的图像分析系统。

> 项目定位：医学图像处理与人工智能应用实践项目，主要用于深度学习模型训练、皮肤病变区域分割、图像可视化及大语言模型辅助分析的学习与研究。

---

## 一、项目简介

皮肤镜图像能够提供皮肤病变区域的细节信息，但病变区域的形状、颜色、边界和纹理存在较大差异，人工识别与标注需要一定的专业知识。

本项目尝试利用深度学习技术，实现皮肤病变区域的自动分割。

项目采用 U-Net 卷积神经网络作为核心分割模型，以 PH²（PH2）皮肤镜图像数据集作为实验数据，通过图像预处理、数据集划分、模型训练、测试集评估和预测结果可视化，完成皮肤病变图像二值分割任务。

在基础分割功能完成后，计划使用 Streamlit 搭建交互式网页，并结合大语言模型，为图像分析结果提供辅助解释。

### 项目主要目标

1. 熟悉医学图像处理的基本流程。
2. 掌握 PyTorch 数据集加载与模型训练方法。
3. 理解并实现 U-Net 图像分割网络。
4. 实现皮肤病变区域的自动二值分割。
5. 使用 Dice 系数等指标评价模型性能。
6. 通过可视化方式直观展示模型预测结果。
7. 探索深度学习与大语言模型结合的应用方式。

## 三、项目技术原理

### 1. 图像预处理

在模型训练之前，需要对原始皮肤镜图像及对应的病变掩码进行预处理。

主要步骤：

1. 读取原始皮肤镜图像。
2. 将原始图像统一转换为 RGB 格式。
3. 将对应的病变掩码转换为灰度图。
4. 将图像按比例缩放至 256×256 的目标画布范围。
5. 对不足的区域进行填充，避免直接拉伸导致图像变形。
6. 原始图片使用双线性插值，掩码使用最近邻插值。
7. 将图像转换为 PyTorch Tensor。
8. 将图像像素归一化至 [0,1]。
9. 将掩码转换为二值数据，背景为 0，病变区域为 1。

原始图像与对应掩码使用相同的几何变换，保证二者在空间位置上保持一致。

### 2. 数据集划分

本项目使用 PH² 数据集，共包含 200 组原始图片及对应病变掩码。

数据集采用随机划分方式，比例为 70% : 15% : 15%。

| 数据集 | 数量 | 用途 |
|---|---:|---|
| 训练集 Train | 140 | 模型学习 |
| 验证集 Val | 30 | 模型性能验证及最佳模型选择 |
| 测试集 Test | 30 | 最终模型性能评估 |
| 总计 | 200 | 全部样本 |

数据集划分信息保存于：

`dataset/split.csv`

该文件记录病例编号、原始图片路径、掩码路径及所属数据集。

### 3. U-Net 模型

本项目采用经典 U-Net 网络结构完成二分类图像分割任务。

U-Net 主要由编码器、解码器和跳跃连接组成。

**编码器（Encoder）**

通过卷积和最大池化逐步提取图像特征，降低特征图空间尺寸，同时增加特征通道数。

**解码器（Decoder）**

通过转置卷积逐步恢复特征图的空间尺寸，生成与输入图片相对应的分割结果。

**跳跃连接（Skip Connection）**

将编码器中提取的浅层特征传递给对应的解码器，帮助模型保留图像边缘和空间位置信息。

当前模型使用的主要通道配置：

- 输入通道：3
- 第一层：32
- 第二层：64
- 第三层：128
- 第四层：256
- 第五层：512
- 输出通道：1

输入图片尺寸为：

`[N, 3, 256, 256]`

模型输出尺寸为：

`[N, 1, 256, 256]`

输出为未经过 Sigmoid 的预测值，训练阶段使用 BCEWithLogitsLoss 计算二分类分割损失。

推理阶段使用 Sigmoid 将输出转换为概率，并通过 0.5 阈值生成二值预测掩码。

### 4. 模型训练思路

训练过程主要包括：

1. 加载训练集与验证集。
2. 初始化 U-Net 模型。
3. 定义损失函数。
4. 定义 Adam 优化器。
5. 将训练图片输入模型。
6. 计算预测结果与真实掩码之间的损失。
7. 通过反向传播计算梯度。
8. 更新模型参数。
9. 使用验证集评估模型。
10. 根据验证集 Dice 保存最佳模型。

当前使用的训练参数：

| 参数 | 当前设置 |
|---|---|
| Epochs | 5 |
| Batch Size | 2 |
| Learning Rate | 0.0001 |
| Optimizer | Adam |
| Loss Function | BCEWithLogitsLoss |
| Device | CPU |
| Input Size | 256×256 |

最佳模型参数保存位置：

`checkpoints/best_unet.pth`

## 四、模型评价指标

本项目使用 Loss 和 Dice 系数评价模型的分割表现。

### 1. BCEWithLogitsLoss

用于计算模型预测结果与真实二值掩码之间的差异。

Loss 越低，通常说明模型预测与真实标注之间的差异越小。

### 2. Dice Coefficient

Dice 系数用于衡量模型预测区域与真实病变区域之间的重合程度。

计算公式：

\[
Dice = \frac{2|P\cap G|}{|P|+|G|}
\]

其中：

- P：模型预测的病变区域。
- G：真实标注的病变区域。
- P ∩ G：预测区域与真实区域的交集。

Dice 的取值范围为 [0,1]，越接近 1 表示两个区域的重合程度越高。

| 评价指标 | 结果 |

本项目使用 PH²（PH2）皮肤镜图像数据集。

https://www.kaggle.com/datasets/spacesurfer/ph2-dataset

下载并解压后，数据目录需要符合以下结构：

```text
dataset/
└── PH2Dataset/
    └── PH2 Dataset images/
        ├── IMD002/
        │   ├── IMD002_Dermoscopic_Image/
        │   │   └── IMD002.bmp
        │   │
        │   ├── IMD002_lesion/
        │   │   └── IMD002_lesion.bmp

        ├── IMD003/
        │   ├── IMD003_Dermoscopic_Image/
        │   └── IMD003_lesion/
```

1. 原始图像与对应的 lesion 掩码必须保持病例编号一致。

当前开发环境将原始数据集放置在项目目录之外，`split.csv` 保存的是本机图片路径。
